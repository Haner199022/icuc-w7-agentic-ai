## 核心亮点

- **前 14 页零英文黑话 + 第 15 页 5 分钟翻牌认词**：先动手改出第 2 版，再轻松认识 `Zero-shot`、`Agentic Workflow`、`Reflection`、`VLM`。
- **13 个真实可玩交互网页全内嵌**：
  - `P02`：4 版演进独立可玩网页（灰框 → 水彩初成 → 零卡球 → 4 展板美术馆）
  - `P03`：反面示范白屏翻车网页 vs 高分示范第 2 版真水彩对照
  - `P06`：4 步拆解实时嵌入 4 个独立交互样板（痛点解剖 / 素白手感 / 真水彩材质 / 4 项验货台）
  - `P07`：放权 3 档滑块实时切换 3 个可玩样板（像素标尺 / 挑刺微调 / AI 全撒手抢挡板）
  - `P10`：干瘪灰框初稿 → 圈出 3 处硬伤 → 真机 WebGL2《PIGMENT.》水彩美术馆三幕实玩
- **紧凑 30 分钟双轮实操闭环**：`P11 第 1 轮（14′）` → `P12 同桌互玩（6′）` → `P13 第 2 轮定点精修（10′）`。
